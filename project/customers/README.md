# Customer discovery notes (confidential)
One file per conversation: `YYYY-MM-DD-<company-or-alias>.md` with: who (role, not necessarily name),
context, current derivative-redesign process, iteration counts and cycle times quoted verbatim,
tools used, willingness to share reference layouts, budget owner, objections, follow-ups.
Tag any statement that bears on a charter assumption with its id (e.g. `[A-T4]`) so /thesis-review can
find it. Never paste customer files, drawings, or data into this repository; reference them by an ID
stored in the private data vault.
